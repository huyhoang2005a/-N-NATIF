# UI Reference — R2M V5

5 file trong thư mục này là bản phác thảo hướng thiết kế (React + Tailwind,
dữ liệu giả, không nối API thật) — dùng làm tài liệu tham chiếu khi dựng UI
thật trong apps/web, KHÔNG được import/copy nguyên trạng vào production.

Trích ra từ đây: hệ thống màu, component pattern (Card, StatusPill,
CitationChip...), cấu trúc trang/luồng điều hướng.
Không trích: dữ liệu mẫu, cách quản lý state bằng useState cấp cao nhất
(role switcher), cách 4 role gộp chung 1 file.
